# ai-fun-fact-generator

A simple website that generates fun fact about the selected topics using Gemini AI.

**Live demo :**
https://anvvar.pythonanywhere.com/

## How to use :

Click on a topic, wait for a few seconds, get a short fun fact from ai.

## Tech stacks used :

- Frontend : HTML, CSS, JS
- Backend : Python
- AI : Google Gemini API
- Hosted on : PythonAnywhere


## What i learnt :
-What is API and how to use it
-The importance of protecting API keys, and how to protect them using .env and venv
-How to deploy a python web app to PythonAnywhere
-Reading, Understanding, and fixing error messages
